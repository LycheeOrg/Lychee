## Vision & Success Criteria
Users who already use Flisk can start Lychee with `flisk up lychee`, and anyone can run the generated Compose file, with the same data as a `docker-compose.yaml` install. Success: S-104-01 … 05 pass.

## Scope Alignment
- **In scope:** FX-104-01 … 03, `docs/FLISK.md`, one README line, one `.gitignore` exception, one CI workflow.
- **Out of scope:** N-104-01 … 03.

## Dependencies & Interfaces
Flisk CLI 1.4.31 or later (1.4.27 has the fields; 1.4.30 needs none of the FR-104-06 … 08 workarounds; 1.4.31 also does not start Flisk's own PostgreSQL, which Lychee does not use), flisk-import 0.16.0, @flisk-sh/flisk-export 0.9.0 (see the spec's *Pinned versions*).

## Assumptions & Risks
- **Assumptions:** maintainers accept an optional second start path (Q-104-01).
- **Risks / Mitigations:** drift between `docker-compose.yaml` and `service.json` → CI check (FR-104-04) and `flisk import .` to re-read the Compose file.

## Implementation Drift Gate
Re-run the per-service `docker compose config --no-interpolate` comparison and S-104-03 after implementation; record results in the PR.

## Increment Map
1. **I1 – Service files and generated Compose**
   - _Steps:_ `FLISK_IMPORT_PACKAGE=flisk-import@0.16.0 flisk import . --yes`; FR-104-10 health-check override (`jq`); `npx @flisk-sh/flisk-export@0.9.0 compose . --force`; `.gitignore` exception.
   - _Commands:_ `flisk config verify`; `echo "APP_KEY=base64:$(openssl rand -base64 32)" > .env`; `docker compose --env-file .env -f .autogenerated/docker-compose.yml config` (bind sources must resolve to `<repo>/lychee/*`).
   - _Exit:_ FR-104-01 … 03 met; comparison shows only documented differences.
2. **I2 – Docs and CI**
   - _Steps:_ `docs/FLISK.md`, README line, `.github/workflows/flisk.yml`.
   - _Steps (CI):_ re-import from `docker-compose.yaml`, FR-104-10 health-check override (`jq`), export, in a scratch copy; `git diff --exit-code -- services .flisk .autogenerated`; normalised per-service `docker compose config` comparison of both files (FR-104-04).
   - _Exit:_ FR-104-04/05; S-104-04 fails as expected both on an edited `service.json` and on an edited `docker-compose.yaml`.
3. **I3 – Evidence**
   - _Steps:_ S-104-01 … 05 on a fresh machine; screenshots and logs in the PR.
