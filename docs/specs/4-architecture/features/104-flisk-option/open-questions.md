## Question Details

### Q-104-01 – Optional Flisk start path
- **Option A (recommended):** Accept it as an option; `docker-compose.yaml` stays the documented main path (as biolend83/tubehaus did in #40). Pros: no change for existing users; Flisk users get `flisk up`. Cons: two descriptions of one stack, kept in step by CI.
- **Option B:** Keep it outside the repository (a gist or the Flisk docs). Pros: nothing to maintain here. Cons: drifts silently.
- **Option C:** Decline.

### Q-104-02 – Location of the generated Compose file
- **Option A (recommended):** `.autogenerated/docker-compose.yml`, committed, with a `.gitignore` exception. Pros: clearly generated. Cons: needs `--env-file .env` when run from the root.
- **Option B:** Do not commit it; generate on demand. Pros: one less file. Cons: no plain-Compose path without Flisk.
