## Vision & Success Criteria
One switch (`V8_ENABLED`) runs v8, and v8 runs its listings on v3 only (ADR-109-01). Success: an installation with only `V8_ENABLED=true` behaves like today's installation with all three flags on (NFR-109-01); `V8_ENABLED=false` behaves like today's v7 (NFR-109-03); `resources/js/v8` holds no read of the SoA flag or of the four view getters (FR-109-02); every gating test still runs, against `features.v8` (NFR-109-04).

## Scope Alignment
- **In scope:** FR-109-01 … 06: gate swap on 19 requests + quick naming, removal of `struct-of-array` and `nuxt_ui`, `InitConfig` field removal, `app-v8.ts` boot flag, v8 branch removal, orphan clean-up (Q-109-04), docs.
- **Out of scope:** N-109-01 … 05 (v2 endpoints, v3 payloads, listings without v3, settings removal, shared-store v2 branches).

## Assumptions & Risks
- **Assumptions:** `phpunit*.xml` keep `V8_ENABLED=true`; Laravel rebuilds the application per test, so `config([...])` in a test does not leak (the `tearDown()` resets of the SoA flag can go).
- **Risks / Mitigations:**
  - v8 code that reads `is_struct_of_array_enabled` before `LycheeState.load()` resolved (e.g. `Map.vue` notes the field "defaults to false until this load"): setting it in `app-v8.ts` before mount removes that window; check each such comment when removing branches.
  - A v2-only v8 component still reached from a non-flag path (e.g. `PhotoThumbPanel.vue` for the filtered album, FR-109-06): orphans are listed by import search after the branch removal, never guessed; deletion waits for Q-109-04.
  - Upgrading installations: `NUXT_UI_ENABLED=true` without `V8_ENABLED` falls back to v7, `V8_ENABLED=true` without `NUXT_UI_ENABLED` switches to v8 (ADR-109-01). Release-note line in T-109-11.
  - `vp check --fix` repo-wide breaks `EmbedCodeDialog.vue`: run `vp check` scoped to the changed files.

## Release Note (for the release notes, kept outside this repo)
`NUXT_UI_ENABLED` and `STRUCT_OF_ARRAY_ENABLED` are gone: `V8_ENABLED=true` now serves the v8 interface, enables the v8 features and its struct-of-arrays listings. If you ran v8 with `NUXT_UI_ENABLED=true` only, add `V8_ENABLED=true`. If you set `V8_ENABLED=true` on the v7 interface (for example for face recognition), that now switches you to v8; remove it to stay on v7, without the v8 features.
